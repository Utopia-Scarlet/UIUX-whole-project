# LoveStory Case Study Visual Evidence (`public/lovestory/case-study/`)

Authentic product interface screenshots rendered from the real LoveStory web application frontend (`https://love-story-archive-production.up.railway.app`) using Playwright (`scripts/capture-lovestory-evidence.mjs`) at `1440 × 900` (desktop landscape, `2x` DPR) and `390 × 844` (mobile portrait, `2x` DPR) with strictly non-sensitive architectural and landscape demonstration records.

## Subdirectories

- `index/` — Restrained visual previews for the 5 Archive Index entries (`ls-index-01-needs` through `ls-index-05-iterations`).
- `requirements/` — Visual evidence for Archive 01 (`Why We Built It`): `req-01-shared-space`, `req-02-time-place`, `req-03-private-boundary`, `req-04-future-mobile`.
- `architecture/` — Visual evidence for Archive 02 (`Connecting Memories`): `arch-hub-our-world`, `arch-node-moments`, `arch-node-timeline`, `arch-node-memory-map`, `arch-node-future-plans`, `arch-node-countdown`, `arch-node-private`.
- `experience/` — Visual exhibition assets for Archive 03 (`Experience the Memories`): desktop landscape (`16:10`) and mobile portrait (`9:19.5`) captures across Moments, Timeline, Memory Map, Future Plans, Private Lock Gate, and Mobile Composer.
- `design-system/` — Dual-surface (`Dark Archive` vs. `Paper & Ink`) interface comparisons for Archive 04 (`Made With Intention`): `ds-dark-hub` / `ds-light-hub`, `ds-dark-timeline` / `ds-light-timeline`, `ds-dark-unlock` / `ds-light-unlock`.
- `iterations/` — Verified iteration results for Archive 05 (`Built & Beyond`): `iter-01-shared-space-sync`, `iter-02-chronological-order`, `iter-03-desktop-memory-sheet`, `iter-03b-mobile-composer`.
